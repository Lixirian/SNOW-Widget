# SNOW Widget : distribution

Ce dépôt sert uniquement à diffuser les versions du SNOW Widget : le manifeste `latest.json`
et, dans les [releases](../../releases), les paquets signés et le lanceur `SNOW-Widget.cmd`.
Il ne contient pas le code de travail.

Chaque paquet et chaque manifeste sont signés (RSA 3072, SHA-256). L'application et le lanceur
refusent tout contenu dont la signature ne correspond pas à la clé publique de l'éditeur.

Outil interne : aucune demande de support n'est traitée ici. Les issues sont désactivées.
Ne joignez jamais de journal ni de capture contenant des données de tickets.
